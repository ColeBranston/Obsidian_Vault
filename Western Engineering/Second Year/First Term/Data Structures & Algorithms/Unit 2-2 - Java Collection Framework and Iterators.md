### What is Hashing?

- A technique that determines a storage index or location for storing an item in a [[Data Structure]].

- The hash function receives the search key (e.g., the element that needs storage) and returns the index of an array where the search key is stored.
	- In this case, the array is called the hash table, and
	- the index is known as the hash-code or hash-index.

- A perfect hash function maps each search key into an index of the hash table.

- It saves time in [[Searching]] or accessing any data item.
