#### Summary: Logarithmic

- An algorithm with the O(logn) time complexity is called a logarithmic algorithm. 

- The base of the log is 2, but the base does not affect a logarithmic growth rate (why?), so it can be omitted. 

- The logarithmic algorithm grows slowly as the problem size increases. **If you square the input size, you only double the time for the algorithm.**
