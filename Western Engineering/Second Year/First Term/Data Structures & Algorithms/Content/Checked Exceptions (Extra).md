- Java forces the programmer to deal with checked exceptions

- If a method declares checked exception (i.e., an exception other than **Error** or **RuntimeException**) one must follow one of the following methods:
	- In the calling method declare (use keyword **throws**) the exception to throw **or**
	- Invoke the exception in a try-catch block.
