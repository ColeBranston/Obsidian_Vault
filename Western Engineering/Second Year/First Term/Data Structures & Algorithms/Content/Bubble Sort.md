
- Bubble sort is a simple and easy to implement algorithm. 

	- It steps through the data-set from one end to the other, and compares adjacent pairs of elements in each pass (one-pass: whole set is traversed for one time) 
	- The elements are swapped if they are in the wrong order (expected order: ascending). 
	- After the first pass, the last element becomes the largest in the array. After the second pass, the second to the last element becomes the second largest in the array, and so on. 
	- The pass through the unsorted portion of the list is repeated until the list is sorted completely.
