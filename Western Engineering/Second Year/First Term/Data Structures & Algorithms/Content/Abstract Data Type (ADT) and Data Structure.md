It represents the ways of organizing data in the computing environment. An ADT provides a specification of:

- a set of data that is stored and
- a set of operations that can be performed on the data

- ADT derives the names from the sense that it is independent of various concrete implementations and so it’s an [[entity]] (interface or abstract-[[class]]) with some abstract methods.

**Data Structures** are realized by implementing ADTs within a programming language.

#### Terminology

1. [[Collection]]
	1. [[Linear]]
	2. [[Nonlinear]]
2. [[Container]]

The terms [[Collection]] & container are sometimes used interchangeable.
