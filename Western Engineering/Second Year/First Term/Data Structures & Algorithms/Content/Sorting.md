Sorting refers to the process of rearranging a set of data items either in ascending or in descending order based on a **key** in the data-set.

- A **key** can be grade of a student, in a list of students’ grades that contains students’ names and corresponding grades. In this case, the list will be sorted based on the grades of the students

- If the key is student’s last name, the the list will be sorted based on the last names.

**Note:** The sorting algorithms in all the ADTs in Java have been implemented in ascending order, and hence, here, ascending order has been considered in implementing different sorting algorithms
