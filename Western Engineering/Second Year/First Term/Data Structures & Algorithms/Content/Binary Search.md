
- Binary search is a quick and efficient method that uses the **Decrease and Conquer** approach (a simpler version of Divide and Conquer approach, discussed in Unit 3 – Part 1). 

- **Prerequisite**: It requires the data set to be sorted. 

- It divides the input collection into approximately equal halves, and with each iteration compares the search-element with the element in the middle. 

- If the element is found, the search ends. Otherwise, it continues looking for the element by dividing and selecting the appropriate portion of the array (by comparing the search-element with the middle element.) 

- The iterative version of this algorithm has been presented and discussed in Unit 3 – Part 2.
