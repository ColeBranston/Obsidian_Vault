**Important (Shown In Above Example)** 

- if both the operands in the division operation in Java are of *int* type data, the output of a/b with b = 0, will result in an **Arithmetic Exception** (/ by zero) call.

- if both the operands in Java is a 0, and one is or both are a *non-integer* type, the output will result in ***NaN*** (Not a number).

- if one of the operands in division operation in Java is *double* or *float* type data, the output of a/b with b = 0, will be "infinity". It'll **not result** in an **Arithmetic Exception** call.
