**Exception**: (short-form of *exceptional event*) is an event that represents a [[Runtime Errors|run-time error]] or run-time condition that prevents a program to run (execute) normally.

- An exception might result due to an unavailable resource, unexpected input from a user, or simply a logical error on the part of the programmer.

- In Java, *exceptions are objects* that are generated by a code that encounters an unexpected situation. This is labelled as "An exception is thrown (generated)"

>[!Default Exception Handler]
>In any unexpected code-execution situation arises, an exception is thrown by default. In this case, the program terminated gracefully by activating the **default exception handler** that prints an error message on the output console.

>[!Exception-Handling]
>Beside terminating the program gracefully from inside the code, java provided an option to the programmer to continue the program by handling the exception inside the code -  this non-default procedure is known as **Exception-Handling**

#### The Classes Related to Unexpected Code-Execution

- The parent classes are:
	- Error (takes care of the **system errors**)
	- Exception (takes care of all **non-system related errors**)

**Note:** We can define our own exception classes by deriving them from the Exception class or one of its derived classes.
