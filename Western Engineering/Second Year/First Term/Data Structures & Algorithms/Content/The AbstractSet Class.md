- The AbstractSet [[class]] extends AbstractCollection, implements toString() method (from [[Object]] Class) and implements Set.

- The AbstractSet class provides concrete implementations for the equals() and the hashCode() methods (from Object class).

- The hash code of a set is the sum of the hash codes of all the elements in the set.

- Since the size() and iterator() methods (from [[Collection]] interface) are not implemented in the AbstractSet class, AbstractSet is an abstract class.
