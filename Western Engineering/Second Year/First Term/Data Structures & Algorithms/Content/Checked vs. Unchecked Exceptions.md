# Note on Unchecked exceptions

- In most cases, unchecked exceptions reflect programming logic errors that are not recoverable. E.g.,

![[Null Pointer Exception]]

![[Index Out of Bounds Exception]]

- These are the **[[logical errors]] that should be corrected in the program.**
- Unchecked exceptions can occur anywhere in the program.
- To avoid cumbersome overuse of try-catch [[blocks]], Java **does not require you** to write code to catch unchecked exceptions.
