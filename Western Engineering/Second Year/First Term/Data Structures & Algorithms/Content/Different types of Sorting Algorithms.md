Simple ones: The simple [[Sorting]] algorithms are notably easier to understand and implement but are generally slower than the other ones.

- [[Bubble Sort]] (Stable)
- [[Insertion Sort]] (Stable) 
- [[Selection Sort]] (unstable; can be coded to make it stable  
- [[Shell Sort]] (unstable)

Advanced ones: Faster than the simples ones - good for sorting a huge dataset

- Merge Sort (Stable) 
- Quick sort (unstable; can be made stable, using a stable Partition-algorithm) 
- Radix Sort / Bucket Sort (unstable) 
- Heap Sort (unstable)
