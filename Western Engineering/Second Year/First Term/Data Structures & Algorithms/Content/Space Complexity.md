
- Time is not the only thing that matters in an algorithm. We also care about the amount of memory or space required by an algorithm. 
- Space complexity is a parallel concept to time complexity. If we **need to create an array of size n**, this will require O(n) space. If we need a two-dimensional array of size n x n, this will require O(n2 ) space. 
- We will explore more on space complexity further down the road.
