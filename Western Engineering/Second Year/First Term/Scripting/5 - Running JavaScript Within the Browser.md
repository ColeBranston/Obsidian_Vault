
>[!What is a Scripting Language]
>- A language used to automated a set of tasks that will be executed one by one.
>- Interpreted rather than compiled
>- **JavaScript** is one of those scripting languages, other examples include Perl, Python, etc.

### Console

The “Console” is a command line interface that allows the  
developers to test their code as well as log information from the  
code while it’s executing

![[Pasted image 20240913120150.png]]

**You can run JavaScript in this command line as well.**

→ When you hit enter this statement will be submitted to the JS  
engine provided by the browser and the alert message will appear  
without affecting the original code.
