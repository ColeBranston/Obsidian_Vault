### 4. Calculate the Unit Contribution and Contribution Margin Rate Per Box and Per Average Order of Protein Bars for Each Distribution Channel

**Cost per box (12 bars):**

- **Raw materials**: $15
    
- **Labor**: $2
    
- **Total variable cost per box**: $15 + $2 = $17
    

**Selling Prices:**

- **Website**: $55/box
    
- **Amazon.ca**: $54/box
    
- **In-store**: $35/box (wholesale price to FCM)
    

**Unit Contribution**:

- **Website**: $55 - $17 = $38
    
- **Amazon.ca**: $54 - $17 - $16 = $21 (including $8 referral fee and $8 FBA fee)
    
- **In-store**: $35 - $17 = $18
    

**Contribution Margin Rate**:

- **Website**: $38 / $55 = 69.1%
    
- **Amazon.ca**: $21 / $54 = 38.9%
    
- **In-store**: $18 / $35 = 51.4%
    

### 5. Calculate and Analyze the Number of Orders Required to Break Even Using Each Distribution Channel

**Fixed Costs**:

- **Website**: $70/month (website fees) + $900/month (social media management) = $970/month
    
- **Amazon.ca**: $360/year = $30/month (annualized)
    
- **In-store**: $1,500 (rent) + $1,000 (transportation) = $2,500/month
    

**Break-even Analysis**:

- **Website**:
    
    - Break-even point (boxes) = Fixed Costs / Unit Contribution
        
    - $970 / $38 ≈ 26 boxes
        
- **Amazon.ca**:
    
    - Break-even point (boxes) = Fixed Costs / Unit Contribution
        
    - $30 / $21 ≈ 2 boxes
        
- **In-store**:
    
    - Break-even point (boxes) = Fixed Costs / Unit Contribution
        
    - $2,500 / $18 ≈ 139 boxes
        

### 6. Which Distribution Channel is Expected to be Most Profitable in 2023?

Based on the contribution margin and break-even analysis:

- **Website**: High contribution margin (69.1%) and moderate break-even point (26 boxes).
    
- **Amazon.ca**: Lower contribution margin (38.9%) but very low break-even point (2 boxes).
    
- **In-store**: Moderate contribution margin (51.4%) but high break-even point (139 boxes).
    

The **website channel** is expected to be the most profitable due to the highest contribution margin and a manageable break-even point.
