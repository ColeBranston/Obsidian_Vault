- The textbook classifies the regions over which we are calculating a double integral into Type-1 and Type-2 regions. This designation is not important, and it’s certainly not important to know exactly which is which. It is however important to understand that we are going to approach double integrals in one of two ways:

	1. we are either going to seek to “eliminate” the variable y via a first integration, which will then leave us with a normal integral over x only (textbook refers to this as a “Type-1” region- see Figure 2), or 
	2. we are going to seek to eliminate the variable x via a first integration, which will then leave us with a normal integral over y only (“Type-2”, again see Figure 2).

![[Pasted image 20250127084814.png]]

You often have a choice in whether you want to treat a region as Type-1 or Type-2. Consider the region in Figure 3. In this figure, we are only depicting the region over which we are going to integrate some to-be-determined function (we are not integrating Figure 3 “itself”)- this will be more obvious in a first example. But we could in this case eliminate y first and then integrate with respect to x, or vice versa. In Figure 3, we could say that the lower limit for y is y = x2 and the upper limit for y is y = 4. We would integrate our function with respect to y first then, and have a result of a 1D integral with respect to x only, where 0 ≤ x ≤ 2. This would be treating the region as “Type-1”. We’ll just say this is “first integrating with respect to y, then x”

Alternatively we could say that the lower limit for x is x = 0 and the upper limit for x is x = √y. We would integrate our function with respect to x first, then we would have a 1D integral with respect to y only. And in that second integral we would have limits for y of 0 ≤ y ≤ 4.
