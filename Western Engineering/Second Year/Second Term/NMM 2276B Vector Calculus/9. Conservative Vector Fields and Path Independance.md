
### Path Independence

- We have seen that a line integral (or path integral, or contour integral- we will use any of these terms depending on context) is in general dependent on the path itself. We would have:

$$
\vec{G}(x, y) = P(x, y) \hat{i} + Q(x, y) \hat{j}, \quad \text{and}
$$

$$
\vec{r}(t) = f(t) \hat{i} + g(t) \hat{j}, \quad a \leq t \leq b, \quad \text{which defines some path } C
$$

$$\text{so we have}$$

$$
\int_{C} \vec{G} \cdot d\vec{r} = \int_{C} [P dx + Q dy],
$$
What weare going to see is that for some special vector fields, the path integral will not depend on C at all, but only the end points of C:

$$A=(f(a),g(a)) \text{ and }B=(f(b),g(b)).$$
The fact that we have shown the curve in Eq. 2 as parameterized by *t* is not important
- this analysis will be true regardless of how we represent/parameterize the curve (ie, we do not have to be parameterize or represent the curve as a function of *t* for any of this discussion to be true). It's just a but easier to talk about the curve in general if we htink about it as parameterized by *t*.

**Fundamental Theorem of Calculus:**

$$\int _a ^bf'(x)dx = f(b)-f(a).$$

So this says that if we are integrating a function that is actually a derivative of another function, then the integral only depends on the end points of the interval (and using our new language, we can think of that interval as a very simple, straight-line 1D "path").

### Conservative Vector Functions

Let $C$ be some path on an open region $R$ of the $xy$ plane, and the path is defined by some $$\overset{->}{r}(t) = x(t)\hat{i} + y(t)\hat{j}, \text{ for } a\leq t \leq b$$
**Here it is:** If $\overset{->}{G}(x,y) =P(x,y)\hat{i}+Q(x,y)\hat{j}$ can be written as the gradient of a scalar function $\phi(x,y)$ in $R$, then:

$$\int_C \vec{G} \cdot d\vec{r} = \int_C \nabla \phi \cdot d\vec{r} = \phi(B) - \phi(A),$$
$$
$$
where A = (x(a),y(a)) and B = (x(b),y(b)) are the end points of the curve. The function ϕ(x,y) is called the “potential function” for the vector field ⃗ G(x,y). A vector function ⃗ G is said to be “conservative” if ⃗ G can be written as ∇ϕ, with ϕ being a potential function for ⃗ G.

- Let ⃗ G be a vector field (vector function) defined over an open connected region. The following are equivalent statements (if you can show one of them is true, the others are also true).

$$
\vec{G} = \nabla \phi \text{ for some } \phi. \quad \text{I.e. } \vec{G} \text{ is conservative.}
$$

$$
\nabla \times \vec{G} = 0
$$

$$
\int_C \vec{G} \cdot d\vec{r} \quad \text{is independent of path.}
$$

$$
\oint_C \vec{G} \cdot d\vec{r} = 0 \quad \text{for every closed path } C.
$$

As we said above, if any one of the above statements is true, they are all true. But the f irst two are actually more fundamentally equivalent. The curl of the gradient of any function is always zero:

$$
\nabla \times (\nabla H) = 0, \quad \text{for any } H.
$$
- $\nabla \times \overset{->}{G}=0$ is actually probably the most straight-forward "test" of whether a function is conservative. Given any vector function, you can test if it is conservative just by taking its curl, and if the curl is zero, then you know that function is conservative and all other tests shown above and below it are true as well.

If the vector function is only dependent on two variables (say (x,y) as we often write), there is perhaps an easier test of whether the function is conservative, but it is really just the same thing as requiring the curl be zero:

$$
\vec{F}(x, y) = P(x, y) \hat{i} + Q(x, y) \hat{j}, \text{ is conservative in an open region }R \text{ if:}
$$

$$
\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}, \quad \text{for all } (x, y) \text{ in } R.
$$
- Let's just look at some very simple examples.

1. Determine if the following vector field is conservative if $R^2$:
$$
\vec{F} = (x^2 - 2y^3) \hat{i} + (x + 5y) \hat{j}
$$

Evaluate the partial derivatives that comprise the non-trivial components of the curl of $\overset{->}{F}$
$$
P = x^2 - 2y^3; \quad \frac{\partial P}{\partial y} = -6y^2
$$

$$
Q = x + 5y; \quad \frac{\partial Q}{\partial x} = 1
$$

$$
\frac{\partial P}{\partial y} \neq \frac{\partial Q}{\partial x} \text{ for all } (x, y)
$$

$$
\therefore \vec{F} \text{ is not conservative}
$$
2. Determine if the following vector field is conservative $R^2:$ 

$$
\vec{F} = -ye^{-xy} \hat{i} - xe^{-xy} \hat{j}
$$
Evaluate the partial derivatives that comprise the non-trivial components of the curl of $\overset{->}{F}$

$$
P = -ye^{-xy}, \quad \frac{\partial P}{\partial y} = -e^{-xy} - y(-x)e^{-xy}
$$

$$
= (xy - 1)e^{-xy}
$$

$$
Q = -xe^{-xy}, \quad \frac{\partial Q}{\partial x} = -e^{-xy} - x(-y)e^{-xy}
$$

$$
= (xy - 1)e^{-xy}
$$

$$
\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} \text{ for all } (x, y)
$$

$$
\therefore \vec{F} \text{ is conservative}
$$

### Conservative Vector Fields in 3-Space

There’s really not much to extending the concept of the conservative vector field to 3D. We now accept that the vector field has three components (limiting discussion to Cartesian coordinates at this point, but the criterion and consequences of a vector field being conservative certainly do not depend on coordinate system):

$$
\vec{G} = P(x, y, z) \hat{i} + Q(x, y, z) \hat{j} + R(x, y, z) \hat{k}
$$
and the curve along which we want to consider the integral would be a 3D parameterized curve:$$
\vec{r}(t) = x(t) \hat{i} + y(t) \hat{j} + z(t) \hat{k}, \quad a \leq t \leq b
$$
Let’s just recall the mechanics of Eqn 8, and we’ll see why Eqn. 13 is actually just a component of the more general statement which is Eqn. $8^1$:

$$
\nabla \times \vec{G} = \begin{vmatrix}
\hat{i} & \hat{j} & \hat{k} \\
\partial_x & \partial_y & \partial_z \\
P & Q & R
\end{vmatrix}
$$

$$
= \hat{i} (\partial_y R - \partial_z Q) - \hat{j} (\partial_z P - \partial_x R) + \hat{k} (\partial_x Q - \partial_y P)
$$

$$
= \vec{0},
$$

$$
\implies \frac{\partial R}{\partial y} = \frac{\partial Q}{\partial z}, \quad \frac{\partial R}{\partial x} = \frac{\partial P}{\partial z}, \quad \frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y}.
$$

So before we move on to the next modules and start to make use of these results, let’s just stop and think for a moment. What does this mean? From a purely mechanical point of view, it means that we have some new options when it comes to calculating the line integral of a conservative vector field. If we know (or can figure out) a potential function for the vector field, then we can calculate the value of the line integral by just taking the difference between the potential function evaluated at the two end coordinates of the curve. Another option that a conservative vector field gives us is to replace one path integral with a different (presumably easier or more interesting) path between the same two end points. Sometimes that is easier to deal with than trying to obtain the potential function.
