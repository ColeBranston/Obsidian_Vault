
**Line Integral:** the integral of a function as it varies along a line or curve.

- When dealing with the line integral there are 2 different functions at play. 

1. First function defines the curve.
2. Second function varies along that curve.

$\therefore$ Must identify both and keep track while working on line integrals

**We are starting with line integrals "in the plane"**, meaning the curve is defined purely within a single plane. -> Function of only $(x,y)$.

### Definitions

- We start with a curve $C$ which is parameterized by $x = f(t)$ and $y = g(t)$ for $a \leq t \leq b$. $A$ is the point $(f(a), g(a))$ and $B$ is the point $(f(b), g(b))$.

- $C$ is a "smooth curve" if $f'$ and $g'$ are continuous on the closed interval $[a, b]$ and not simultaneously zero on $(a, b)$.

- $C$ is a "piece-wise smooth curve" if it consists of a finite number of smooth curves $C_1, C_2, \ldots C_n$ joined end to end.

- $C$ is a "closed curve" if $A = B$. Closed curves are going to be particularly important for us as we move ahead in the course.

- $C$ is a "simple closed curve" if $A = B$ and the curve does not cross itself at any point or number of points.

- If $C$ is not a closed curve, then the positive direction on $C$ is the direction corresponding to increasing values of the parameter $t$.

### Three Forms/Types of Line Integrals in the Plane

Let $G=G(x,y)$ defined on the region of the plane which contains the smooth curve $C.$ We don't need to worry about what the exact curve $C$ is at this point.

1. The line integral of $G$ along $C$ with respect to $x$ is: $\int_C G(x, y) \, dx.$

2. The line integral of $G$ along $C$ with respect to $y$ is: $\int_C G(x, y) \, dy.$

3. The line integral of $G$ along $C$ with respect to the arclength along the curve is: $\int_C G(x, y) \, ds.$

- Assume that $C$ is parameterized by $x = f(t)$ and $y = g(t)$, with $a \leq t \leq b$.

To evaluate a contour integral in this case, we replace $x$ and $y$ with the corresponding function of $t$, and then replace $dx$ or $dy$ with $f'(t)dt$ or $g'(t)dt$. If the contour integral is with respect to the arclength, then we set $ds = \sqrt{[f'(t)]^2 + [g'(t)]^2} dt$ where $ds$ is the differential step along the curve $C$.

So the prev. contour integrals become: 

1. $$\int_C G(x, y) \, dx = \int_a^b G(f(t), g(t)) f'(t) \, dt$$
2. $$\int_C G(x, y) \, dy = \int_a^b G(f(t), g(t)) g'(t) \, dt$$
3. $$\int_C G(x, y) \, ds = \int_a^b G(f(t), g(t)) \sqrt{[f'(t)]^2 + [g'(t)]^2} \, dt. $$
### Line Integrals In The Plane, Explicit Function of $C$

- Now we consider the case where $C$ is not defined as a parameterized group of functions (ie. as we had above with everything parameterized by $t$), but is instead provided as an explicit function $y=f(x)\text{ for } a\leq x \leq b.$

- In this situation we will use either $x$ or $y$ as the integration parameter.

- To start, let's use the more familiar case of $x$ as the integration parameter. In this situation we then replace all $y$ instances with $f(x)$, replace $dy$ with $f'(x)dx$, and (if we are doing a line integral with respect to the arc length) replace $ds$ with $\sqrt{1 + [f'(x)]^2} dx$.

1. $$\int_C G(x, y) \, dx = \int_a^b G(x, f(x)) \, dx$$

2. $$\int_C G(x, y) \, dy = \int_a^b G(x, f(x)) f'(x) \, dx$$

3. $$\int_C G(x, y) \, ds = \int_a^b G(x, f(x)) \sqrt{1 + [f'(x)]^2} \, dx$$
