# Common Commands

`git init` -> creates the git environment
`ls` -> lists all directory's in the repo/env
`ls -a` -> shows all files in the directory including hidden ("." in start of files are hidden)
`git status` -> checks to see if git is active in the current directory and any staged or unstaged changes
`touch index.js` -> creates the file named "index.js"
`vim index.js` -> opens the file in a visual editor, "vim", close vim with `wq` input
`git add .` -> stages all current files in the directory
`git add index.js` -> stages specifically the changes and creation of index.js
`git commit -m "This is a message"` -> commits the change with a message
`git branch` -> shows you all the branches
`git branch feature` -> creates a branch called "feature"
`git checkout feature` -> checks out "feature" branch (changes current version to new one)
`git merge feature` -> merges current branch with "feature" branch
`git log` -> displays messages and commit history
`git log --graph` -> shows messages and commit history in cool way
`rm index.js` -> will remove the "index.js" file
`mkdir work` -> creates folder named "work"
`mv index.js file.txt work` -> moves "index.js" and "file.txt" into new work folder

**When Merge Conflict**

`git status` -> indicates the merge issue
`git diff main` -> shows the differences between branches and files (indicates what to fix)

**Then use vim or other editor to change and alter files to correct lines** -> Can also remove conflicting files
