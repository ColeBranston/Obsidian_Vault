
(P1) If dogs are mammals, then dogs are cute.  
(P2) Dogs are cute.  
(C) Therefore, dogs are mammals.

This is an invalid argument form because it assumes that premise P is true because Q is true but assumes that Q can't be true for other reasons. 

That's why with modus tollens that you can assume not P with -> if p then q, not q, $\therefore$ not p because its defined that that q has to be true if p is true also and since q is not true than p isn't either.
