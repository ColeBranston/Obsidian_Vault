## Counter Intuitive Facts About Validity

- The notion of validity is supposed to capture the fairly intuitive notion of one claim following from some others.
- But the term "Validity" has a precise stipulated definition.
- This stipulated definition has some counter intuitive consequences.

#### Counter Intuitive Consequence 1

- Circular arguments are valid.

>[!Circular Arguments]
>![[Circular Arguments]]

**Why Circular Arguments Are Valid**

Review...

___
![[Validity]]
___

- In order for an argument to be invalid, there has to be a way for the premises to be true while the conclusion is false.
- In other words, in order for an argument to be invalid, there has to be a [[Invalidating Counter Examples]].

- In a circular argument, the conclusion is also a premise.
- So, it's not possible for the premises to be true while the conclusion is false.

![[Pasted image 20250121222847.png]]

- In order for an argument to be invalid, there has to be an **invalid counter example** - ie., a logically possible situation in which the premises are true and the conclusion is false. 

![[Pasted image 20250121222944.png]]

#### Counter Intuitive Consequence 2

Arguments with necessarily true conclusions are valid. 

- In some cases, it is logically impossible for an argument's conclusion to be false.

>[!Tautologies]
>![[Tautologies]]

**Why Arguments with Necessarily True Conclusions are Valid**

- In the case of an argument with a necessarily true conclusion, there is no possible way for the conclusion to be false. 
- So, there is no possible way for the premises to be true and the conclusion false. 

![[Pasted image 20250121223552.png]]

- In order for an argument to be invalid, there has to be an **invalidating counter example** -ie. a logically possible situation in which the premises are true and the conclusion false. 

#### Counter Intuitive Consequence 3

- Arguments with inconsistent premises are valid.

>[!Inconsistent Premises]
>![[Inconsistent Premises]]

**Why Arguments with Inconsistent Premises are Valid**

- In order for an argument to be invalid there has to be an **invalidating counter example** - ie. a logically possible situation in which the premises are true and the conclusion false.

![[Pasted image 20250121224049.png]]

### The Moral

- The notation of validity has a precise definition.
- When considering whether an argument is valid, consult that definition.
