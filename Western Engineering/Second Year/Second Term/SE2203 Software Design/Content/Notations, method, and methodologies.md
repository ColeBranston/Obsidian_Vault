## Notations

- a **notation** is a graphical or textual set of rules for representing a model.
	- The Roman alphabet is a notation for representing words.
	- **UML** (unified modeling language), the notation we use through this course, is an object orientated notation for software modeling

## Methods

- a **method** is repeatable technique for solving a specific problem
	- A recipe is a method for cooking a specific dish.
	- A sorting algorithm is a method for ordering elements of a list. 

## Methodologies

- A **methodology** is a collection of methods for solving a class of problems.
	- A seafood cookbook is a methodology for preparing seafood.
	- Software development methodologies decompose the software process into activities.
	- This decomposition include.
		- Sequential Models:
			- For example:  Waterfall model, v-model.
		- Iterative models:
			- For example: Spiral model, Rational Unified Process.
