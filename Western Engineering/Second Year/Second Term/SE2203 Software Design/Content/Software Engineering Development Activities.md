**Include:** 
- Requirements elicitation -> What is the problem? **(Application Domain)**
- Analysis -> Is the problem fully described? **(Application Domain)**
- System Design -> What is the solution? **(Application Domain)**
- Object Design -> What are the best mechanisms to implement the solution? **(Solution Domain)**
- *Implementation* -> How is the solution constructed? **(Solution Domain)**
- *Testing* -> Is the problem solved? **(Solution Domain)**
- *Deployment* -> Can the customer use the solution **(Solution Domain)**
- *Maintenance* -> Are enhancements needed? **(Solution Domain)**
