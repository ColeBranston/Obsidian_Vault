
**1.**

- A matrix is in Row Echelon Form (REF) if:
	- all zero rows are at the bottom.
	- the first non zero element of a row is to the right of the first non-zero element in the row above it.
	- all entries below a first non-zero element of a row are zero.

**Example**

$$
\begin{array}{cc}
2 &4 &-1 &5\\
0 &2 &7&-1\\
0 &0 &0&4
\end{array}
$$
**is REF**

**2.**

A matrix that is REF is in reduced row Echelon form (RREF) if:
- The leading non-zero element of each row is 1.
- The leading 1 in each row is the only non-zero element in its respective column.

**Example**

$$
\begin{array}{cc}
2 &4 &-1 &5 &0 \;|\;\;\;\;7\\
0 &2 &7&-1 &0\;| -4\\
0 &0 &0&4 &0\;|\;\;\;\;0\\
0 &0 &0 &0 &1\;|\;\;\;\;9
\end{array}
$$
**is RREF**

Why is this useful?

Let this be the augmented matrix of a system. (4 equations, 5 unknowns)

$$
f(x) = 
\begin{cases} 
x_1+2x_4=7 \\
x_2 +3x_4 =-4\\
x_3 - x_4 =0\\
x_5 =9
\end{cases}
$$
If a column does not have a leading 1, the corresponding [[free variable]]

can be any real number infinite number of solutions

$x_4=5$ 
$x_3 =5$ 
$x_2 = -3s -4$
$x_1 = -2s +7$

General solution (-2s+7, -3s-4, 5, 5, 9)

Bringing a matrix to RREF is called **row reduction** or **Gaussian reduction**.

Done by using the 3 elementary row operations.
