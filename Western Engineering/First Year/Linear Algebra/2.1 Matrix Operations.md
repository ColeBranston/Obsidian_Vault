
A matrix is a 2D array of numbers

$$
A = 
\begin{cases} 
a_{11} a_{12} ... &a_{1n} \\
a_{21} a_{22} ... &a_{2n} & \text → row \\
......... &....\\
a_{m1} a_{m2} ... &a{mn}

\end{cases}
$$
m x n 

where 
	m: # of rows
	n: # of columns

**Ex.**

$$
v = 
\begin{array}{cc}
|\;\;\;\;3 \;|\\
|-1\;|\\
|\;\;\;\;2\;|
\end{array}
$$
- $\epsilon R^3$
- Also a matrix

A real number a can be thought of as a 1x1 matrix.

Each column of A is a vector in $R^m$:

$$
a_j = 
\begin{array}{cc}
|\;\;\;\;a_1j \;|\\
|\;\;\;\;a_2j\;|\\
|\;\;\;a_mj\;|
\end{array}
$$

You can write the top matrix as the bottom matrix

A square matrix A has dimensions n by n

# Identity (unit) Matrix

$$
A = 
\begin{array} {cc}
a_{11} a_{12} ... &a_{1n} \\
a_{21} a_{22} ... &a_{2n} \\
......... &....\\
a_{m1} a_{m2} ... &a{mn}

\end{array}
$$

$$
I = 
\begin{array} {cc}
1 &0 &0 \text| \\
0 &1 & 0 \text|\\
0 &0 &1\text|

\end{array}

\;\;\;\;\; \text {I on the main diagonal 0 everywhere else}
$$
$$
0 = 
\begin{array} {cc}
0 &0 &0 \text| \\
0 &0 & 0 \text|\\
0 &0 &0\text|

\end{array}

\;\;\;\;\; \text {Zero Matrix}
$$

# Multiplication By A Scalar

A = $[a_{ij}]$ m x n, $k \epsilon R$

$k*A$ a $m \times n$ matrix

KA = $[ka_{ij}]$

**2.1 Cont.**

A. $m \times n$ , B. $n \times p$

→ A*B is $m \times p$ matrix

- B has columns $b_1, b_2, ..., b_p$
($b_1, ..., b_p\;are\;vectors\;in\;R^n$), also can be thought of as matrices of dimension $n \times 1$. 
 - $A \times B = [Ab_1, Ab_2,...Ab_p]$
 
- $Ab_1,...,Ab_p \text{ are the columns of } A  \times B$
