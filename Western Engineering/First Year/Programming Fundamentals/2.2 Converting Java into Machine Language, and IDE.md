**Converting Java programs into machine language: The steps**

- Text Editor
- Compiler
- Bytecode (Virtual Machine Code)
- Java Virtual Machine (JVM)
![[Pasted image 20240115165909.png]]

**The Summary**

- In Java, the program is written in Java-text-editor, known as the source code, and it is saved under any valid name with .java extension. E.g., sourceCode.java.
- The [[Compiler]] in java (known as javac) converts the source code to virtual machine code with .class extension that contains the same source-code name, which is known as byte-code. E.g., sourceCode.class.
- Byte-code is a [[Software]] version of a physical machine, and it is machine independent.
- The machine-independent bytecode can run on any machine that has a Java interpreter (The name of the Java interpreter is java).
- Java [[Interpreter]] is a part of the Java Virtual Machine (JVM)
