*Get an integer number between 4 and 23 inclusive. Find the tripled value (times 3) of that integer number.*

**1. Specification**

- Developed in response to the "requirements"
- Precise statement of what the system will do
- Include:
	- Functional specifications 
	- Input/output specifications 
	- Performance specifications 
- Most important, hardest, most neglected

	**Problem Application**

	- Requirements 
		- Problem Example: Get an integer number between 4 and 23 inclusive. Find the tripled value (times 3) of that integer number. 
		<br>
	- **Specifications** (One probable thought-process) 
		1.Request the user to enter any number 
		2.Read the entered number
		3.Check the number: if less than 4 or greater than 23 display “Invalid” and terminate 4.Calculate the tripled value of the number 
		5.Display the result 
		6.Terminate

**3. Implementation**

- During this step, the programmer writes and compiles the code. 
- Easiest part; there shouldn’t be any surprise in following the steps below: 
	- Pick the platform: PC, Mac, Palm 
	- Pick the language: Java, C++, C, Ada, C#, Python 
	- Pick the IDE (Integrated Development Environment): Eclipse, Netbeans, IntelliJ Idea, MS Visual Studio, Borland C++ Builder, xcode etc. 
	- Implement/Write the code and Compile/Run it. 
- [[Syntax Errors]] in the program are corrected during this step. 
	- Syntax errors are mistakes that a programmer may make by using erroneous grammar of the programming language. No code will compile (compiler-based code), if there is any syntax error in the code.

**4. Testing**

- Second most important part of the process 
- Ensures that the implementation fulfils the specifications 
- A test plan can be generated directly from specifications 
- An item in the test plan contains details about: 
	- Steps that must be followed, 
	- Inputs that must be given and 
	- Outputs that must be observed 
- In testing phase, different boundary conditions, exceptions, [[Logical Errors]], different coding platforms are tested.

**The Problem Example**

1. Run the program
2. Enter "-1". Observe "Invalid"
3. Enter "56". Observe "Invalid"
4. Enter "16". Observe '48'
5. Program must exit
