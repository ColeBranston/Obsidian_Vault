![[External Memory]]![[CPU (Central Processing Unit)]]**RAM (Main Memory) Organization**

- RAM contains: 
	- currently running program instructions. 
	- data used by those programs. 
<br>
- RAM is divided into numbered locations each of which contains one byte of data/information.
- The memory location number is called the address. Each memory location has a unique address, that is, no two memory locations can have the same address. 
	-  Byte is a sequence of 8 bits 
	- Bit stands for binary digit which can have either 1 (TRUE, ON) or 0 (FALSE, OFF) value.
	-  In a [[Computer]] (a digital device), the bits form a pattern that represents a character or a number

**How Is Data Stored in the Memory**

- Computers use zeros and ones because digital devices have two stable states, which are referred to as zero and one by convention. 
- The programmers need not to be concerned about the encoding and decoding of data, which is performed automatically by the system based on the encoding scheme (not covered in this course).
- The encoding scheme varies. For example, character ‘J’ is represented by 01001010 in one byte.
- If [[Computer]] needs to store a large number that cannot fit into a single location (single byte), it uses more than one adjacent locations (adjacent bytes).
