
**Computer/Programming Languages**

- Computers do not understand human languages, so we need to use [[Computer]] languages to communicate with computers.
- We tell a [[Computer]] what to do through programs, which are written in programming languages. 
- Based on level of generalization, programming languages are classified into three main categories – Low-level language, Mid-level language and High-level language. 

![[Low-Level Language or Machine Language]]

Machine (CPU/Processor) dependable. Each CPU has its own [[Machine Language]].
- If we write a program for [[Computer]] A with a specific CPU, and then wanted to run it on computer B, with a different CPU, we will have to rewrite the program in computer B’s Machine Language. 
- Example: 0010 0000 0000 0100

- The Java programming language does not fit into either the compiled language or interpreted language models, rather it is kind of both. 
- The Java [[Compiler]] converts the code written in Java into a virtual machine code called bytecode which is machine independent. 
- This bytecode file can run on any operating system (Windows, UNIX, Mac OS) by using Java Virtual Machine (JVM), for that platform. JVM is the [[Interpreter]] in Java programming language that executes one virtual statement at a time. 
- Thus, Java is an example of a Virtual Machine programming language, that uses both compiler and interpreter.
- A virtual machine (VM) is a [[Software]] implementation of a machine (computer) that executes programs like a real machine. 
	- The JVM executes byte-coded Java programs. 
	- The Java Runtime Environment (JRE) is the on-disk part of Java that creates the JVM. 
	- The Java Development Kit (JDK) allows programmers / developers to create Java programs that can be executed and run by the JVM and JRE. To develop any Java program, we need JDK on our machine
