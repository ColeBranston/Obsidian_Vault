A **URL** (Uniform Resource Locator) is a set of instructions with three separable parts, each answered by a different mechanism:

`https://` `www.someschool.edu` `/someDept/pic.gif`

| Part | Question | Settled by |
|---|---|---|
| **Scheme** | Which protocol, so which port? | an agreed table (`https` = Web over encryption, port 443) · [[Port Number]] |
| **Host name** | Which machine? | the naming system: [[DNS]] |
| **Path** | Which object on it? | nothing: the server decides what the string means (file, query, generated page) |

See also [[URL]] from SE 3316A for the web-technologies side.
