A **database** is a collection of data whose main purpose is to store it — typically **structured**, though it can be semi-structured or unstructured. Data can be images, text, numbers, video, code, or anything else worth storing.

More formally, a database is a **shared collection of logically related data** (plus a description of that data), designed to meet the information needs of an organization. The description of the data is stored in the [[System Catalog]], which enables program–data independence.

**Relational database terminology:**

| Term | Meaning |
|---|---|
| **Table / Relation** | The overall structure holding the data |
| **Columns / Attributes** | The fields describing each record (e.g., Student #, Name, Major) |
| **Rows / Records / Tuples** | The individual entries in the table |

*Example — a Student table: columns `Student #`, `Student Name`, `Major`, `DOB`, `Address`; each student is one row.*
