The DBMS environment has five components that act as a bridge between machine and human:

| Machine side | Bridge | Human side |
|---|---|---|
| Hardware, Software | **Data** | Procedures, People |

- **Hardware** — anything from a single PC to a network of computers
- **Software** — the DBMS itself, the operating system, network software (if needed), and the application programs
- **Data** — the organization's data, described by the [[System Catalog]]
- **Procedures** — instructions and rules for designing and using the database and DBMS (starting/stopping the DBMS, backups, handling hardware/software failures, changing table structures, etc.)
- **People** — see [[Roles in the Database Environment]]
