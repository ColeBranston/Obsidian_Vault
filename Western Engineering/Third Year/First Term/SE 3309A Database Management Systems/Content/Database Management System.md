A **Database Management System (DBMS)** is the software that enables users to define, create, and maintain a [[Database]], and that provides controlled access to it. It sits between users' application programs and the database itself.

**Facilities:**
- **Data Definition Language (DDL)** — specifies data types, structures, and constraints; all specifications are stored in the database (i.e. the [[System Catalog]])
- **Data Manipulation Language (DML)** — the general query language for selecting, inserting, deleting, and updating data

**Controlled access** may include a security system, an integrity system, a concurrency control system, a recovery control system, and a user-accessible catalog.
