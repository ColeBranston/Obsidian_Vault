A **context-free grammar (CFG)** is a finite set of rewriting rules that *generates* a language: start from a start variable, repeatedly replace a variable by the right-hand side of one of its rules, and stop when only terminals remain (see [[Derivation]]). Like a [[Regular Expression]], it is a recipe for producing strings — the set of everything it can produce is its language L(G).

> [!note] Definition 1 — Context-free Grammar
> A CFG is a 4-[[Tuple]] **(V, Σ, R, S)**:
> 1. **V** — a finite set of *variables*
> 2. **Σ** — a finite set of *terminals* (the same Σ as an automaton's [[Alphabet]], deliberately: grammar and machine describe languages over the same alphabet)
> 3. **R** — a finite set of *rules*, each replacing one variable by some concatenation of variables and terminals
> 4. **S ∈ V** — the start variable (by convention, the variable on the left of the first rule)

A bar | abbreviates alternatives: `article → a | the` is two rules.

### Worked example — a grammar for English sentences

```
sentence    → noun-phrase verb-phrase
noun-phrase → cmplx-noun | cmplx-noun prep-phrase
verb-phrase → cmplx-verb | cmplx-verb prep-phrase
prep-phrase → prep. cmplx-noun
cmplx-noun  → article noun
cmplx-verb  → verb | verb noun-phrase
article     → a | the
noun        → boy | girl | flower
verb        → touches | likes | sees
prep.       → with
```

Its four components:
- **V** = {sentence, noun-phrase, verb-phrase, prep-phrase, cmplx-noun, cmplx-verb, article, noun, verb, prep.} — 10 variables
- **Σ** = {a, the, boy, girl, flower, touches, likes, sees, with} — 9 terminals; here a whole word is one "symbol"
- **R** — counting each |-alternative separately, 18 rules
- **S** = sentence

| Sentence | Producible? | Why |
|---|---|---|
| the girl likes a flower | yes | *the girl* as noun-phrase; cmplx-verb → verb noun-phrase gives *likes a flower* |
| boy touches girl | no | every noun enters through cmplx-noun → article noun, so a bare *boy* is impossible |
| a flower sees the boy with a girl | yes | *sees the boy* as cmplx-verb, *with a girl* as prep-phrase — grammatical nonsense: a grammar checks **structure, not meaning** |

> [!question] Is the set of producible sentences finite or infinite?
> Answer — **finite**. Every rule rewrites a variable into "lower" ones (sentence → phrases → word classes), and no chain of rules ever returns to the variable it started from, so derivations cannot grow without bound.

> [!tip] Recursion is what buys infinity
> To describe an infinite language, some variable must be able to reproduce itself (A → 0A1, S → SS). Every grammar in [[CFG for 0n1n]], [[Balanced Parentheses Grammar]] and [[More 1s than 0s Grammar]] does exactly that.

A language generated by some CFG is a [[Context-free Language]].
