L = {w : w contains more 1s than 0s} is generated by the [[Context-free Grammar]]

> **S → T1T**
> **T → TT | 1T | 0T1 | 1T0 | ε**

**How it was built, rule by rule**
- **S → T1T** — even a string with no 0s needs at least one 1, so put one guaranteed extra 1 in the middle
- **T → ε** — lets any T terminate at any time
- **T → 0T1 | 1T0** — whenever a 0 is added, a 1 is added with it
- **T → 1T** — add arbitrarily many extra 1s
- **T → TT** — "spawn" more variables so the rules above combine arbitrarily

| Task | Derivation |
|---|---|
| 11 | S ⇒ T1T ⇒ 1T ⇒ 11T ⇒ 11 (left T → ε, then T → 1T, then T → ε) |
| 011 | S ⇒ T1T ⇒ T1 ⇒ 0T11 ⇒ 011 (right T → ε, left T → 0T1) |
| 110 | S ⇒ T1T ⇒ 1T ⇒ 11T0 ⇒ 110 (left T → ε, then T → 1T0) |
| 01 | **cannot be derived** — equal 0s and 1s, and every derivable string has strictly more 1s |

Several [[Derivation|derivations]] can produce the same string — for 11, starting with the right T → 1T works equally well.

**Claim 1 — nothing extra.** Every string derivable from T has *at least as many* 1s as 0s. Every rule preserves this invariant:

| Rule | Effect on the balance |
|---|---|
| T → ε | zero of each |
| T → 1T | adds a 1 — the balance only improves |
| T → 0T1, T → 1T0 | adds one of each — balance preserved |
| T → TT | two halves with the property; their sum has it too |

So no derivation can escape it, and S → T1T adds one extra 1: every string in the language has **strictly** more 1s than 0s.

**Claim 2 — nothing missing.** Every string with more 1s than 0s is derivable. The proof is an induction on length (omitted); it was verified by computer for every string of length up to 11.
