The **PMI Talent Triangle** names the three skill sets a successful project manager needs. Competence in one does not substitute for the others — the triangle is a set of requirements, not a menu.

- [[Ways of Working]] — the technical craft of running the project
- [[Business Acumen]] — the industry and organizational knowledge that makes the project *worth* running
- [[Power Skills]] — the interpersonal skills that get it done through other people

Where [[Knowledge Areas]] describe what a project manager must *do*, the triangle describes what they must *be good at*.
