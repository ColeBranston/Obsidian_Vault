The **Software Development Life Cycle (SDLC)** is the set of activities used to reach the [[Objective of Software Engineering|SE objective]]. (Googling "SDLC" turns up many variations, but they all cover similar activities.)

| Phase | Answers |
|---|---|
| Requirement Elicitation + Requirements Analysis | What needs to be done? |
| System Design + Object Design | How would it be done? |
| Implementation | Do it |
| Testing | Verify it's doing what it's supposed to |

It's called a **cycle**, not a line — the real process loops back between stages rather than running straight through once.
