The **objective of software engineering** is to move from a:

- **Real system** — vaguely / ambiguously described in plain human language

to a:

- **Computerized system** — very specific, written in a programming language

This happens via three broad activities: **Requirements & Analysis** → **System & Object Design** → **Implementation & Testing**.

> [!note] Not actually linear
> The arrow above shows the *objective*, but real projects never move through this in a straight line — expect looping back.
