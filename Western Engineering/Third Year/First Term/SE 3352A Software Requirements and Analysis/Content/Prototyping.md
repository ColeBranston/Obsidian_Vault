Building a **prototype** is useful on a new project/field to:

- Explore requirements with the user — **requirements capture**
- Explore concepts for a proposed system — **conceptual prototyping**
- Explore technical feasibility — **experimental prototyping**

**Evolutionary prototyping** takes this further: each phase (Requirements → Design → Build → Test → Implement) produces a new *system version*, each built with the intention of evolving into the next — rather than being thrown away.
