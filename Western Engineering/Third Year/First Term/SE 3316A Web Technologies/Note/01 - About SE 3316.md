## What the Course Covers

Focus is on the technology driving web services and web apps — you build a full-stack web app by the end of term.

- **Client side:** HTML, CSS, JavaScript, XML, frameworks (Angular)
- **Server side:** HTTP, ReST, AJAX, scripting, databases, server-side frameworks
- **Also:** the Semantic Web, plus legal, ethical and social issues

### Technology Goals by End of Term

| Area | Target level | How to get there |
|---|---|---|
| HTML & CSS | Intermediate | Self-learning — do an online tutorial; Lab 1 is critical |
| JavaScript | Advanced | In-class material + labs; online tutorial strongly advised |
| Server-side scripts | Introductory | In-class material + labs; get the basic principles solid |

### Lab Requirements

- **Done individually.** No teamwork. All labs checked pair-wise for similarity
- Steady progress required, evidenced by commits
- Pay close attention to the marking rubric
- Project assets (images, data, libraries) must be kept out of Git

### Submission — All Three Steps Required

1. Submit **commit log + zipped code** on Owl before the deadline
2. Submit the **repository to GitHub Classroom** before the demo
3. **Demo your code in lab** within the first week after the deadline

Missing any one of the three means no grade.
