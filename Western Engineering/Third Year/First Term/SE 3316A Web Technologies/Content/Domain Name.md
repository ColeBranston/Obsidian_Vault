A **domain name** is a human-readable name for a **logical entity** (an organization, a service), whereas an [[Internet Protocol|IP address]] is tied to a **physical network**. Mapping one to the other — done by **DNS** (Domain Name Service) — adds a **level of indirection** that lets services be provided flexibly:

- **Load balancing** — one domain → multiple IP addresses
- **Virtual hosting** — multiple domains → a single IP address
- **Easy to remember** — people type names, not numbers

See also [[DNS]] from ECE 4436A.
