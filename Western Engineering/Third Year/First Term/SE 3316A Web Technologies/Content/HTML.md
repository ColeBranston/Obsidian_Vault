**HTML** (Hyper Text Markup Language) is the [[Markup Language]] of the web. Its design is deliberately purist: HTML describes the **logical structure** of a document, and browsers are free to interpret the tags differently when rendering them.

That separation is the whole point — see [[Structure Versus Presentation]], and [[CSS]] for where the appearance actually lives.

HTML is also a very lightweight file format. The same "Hello World!" as a file:

| Format | Size |
|---|---|
| MS Word | 11,274 bytes |
| PDF | 4,915 bytes |
| HTML | 28 bytes |

Overall document skeleton:

```html
<html>
<head>
<title>The Title of the Document</title>
</head>
<body>
...
</body>
</html>
```
