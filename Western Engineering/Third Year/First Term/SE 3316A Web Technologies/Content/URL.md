A **Uniform Resource Locator** identifies a resource by saying **where it lives**. Three parts:

`http://example.com/ex/one/` → **scheme** (`http`) · **server** (`example.com`) · **path** (`/ex/one`)

- **Relative URL** — `sgml/dtd.html`, resolved against the current document's location
- **Fragment identifier** — `http://example.com/page.html#sec1`, pointing at a named position *inside* the resource

A URL is a subset of the more general [[URI]]. Contrast [[URN]], which names a resource without locating it.
