A **code point** is the unique number [[Unicode]] assigns to a character. Code points run from 0 to 1,114,112, and are written in hexadecimal with a `U+` prefix of at least four digits.

HIRAGANA LETTER SA is code point **12,373**, written **U+3055**.

- Code points 0–127 coincide with **ASCII**, which is why ASCII text is valid [[UTF-8]] unchanged
- Some code points are deliberately **never assigned** — [[UTF-16]] relies on this to encode large values, and [[Byte Order]] relies on it to detect endianness
- A code point is not a byte and not a picture: bytes are the [[Character Encoding]]'s business, pictures are the [[Glyph]]'s
