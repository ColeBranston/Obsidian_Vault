**Security services** are the guarantees a secure communication channel can offer:

| Service | Guarantee |
|---|---|
| **Confidentiality** | only sender and receiver can see the message |
| **Integrity** | any attempt to tamper with a message is detected |
| **Authenticity** | the identities of sender and receiver can be verified |
| **Non-repudiation** | sender/receiver cannot deny having sent/received |
| **DoS protection** | protection against denial of service |

[[SSL and TLS]] provides the first three. Plain [[HyperText Transfer Protocol|HTTP]] provides none.
