**Authentication** answers *"Who are you?"* — identifying the user so access can be restricted to authorized users.

| Technique | Status |
|---|---|
| IP address | rarely used |
| [[HTTP Basic Authentication]] | rarely used |
| [[HTTP Digest Authentication]] | rarely used |
| **Form** with username/password fields | common |
| **Federated authentication** (sign in with Google, Facebook, etc.) | common — revisited later with **JSON Web Tokens (JWT)** |
