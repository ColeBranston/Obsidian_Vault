How to use code you found online (or that an LLM produced) without hollowing out your own understanding.

| Wrong way | Right way |
|---|---|
| Search, or ask an LLM | Search for code |
| Copy it into your project | Read through it — can you understand it? |
| Run it | Test it separately — can you understand it *now*? |
| … | Use that understanding to write your own code |
| Profit | Avoid copy/paste |

The distinction isn't the source, it's whether the code passes through your understanding on the way in. Reading and re-implementing gives you something you can debug later; pasting gives you a black box that will fail during a lab demo.

> [!warning] Pasted code can flag you
> Every lab is checked pair-wise for similarity, and AI-generated code is a common source of hits. Keep a dated record of all prompts you use.
