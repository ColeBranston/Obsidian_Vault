**ISO-8859-1** (Latin-1) is another popular [[Character Encoding]]: single-byte code units, only **256 code points**, coinciding with ASCII on 0–127.

It cannot represent general [[Unicode]] — anything outside those 256 slots simply has no representation. And it is one of *hundreds* of encodings still in circulation, which is the whole reason a document has to declare which one it's using:

```html
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
```

Guessing wrong is where mojibake comes from: the bytes are fine, the interpretation isn't.
