A **port** is a 16-bit number (0–65535) that picks out which service on a machine a [[Transmission Control Protocol|TCP]] connection is for. **IANA** assigns ports to standard protocols; ports **0–1023** are the **"well-known" or "privileged" ports**. Full list: `iana.org/assignments/port-numbers`.

| Service | Port |
|---|---|
| FTP | 21 |
| SSH | 22 |
| SMTP | 25 |
| HTTP | **80** |
| HTTPS | **443** |
| HTTP-alt | 8080 |

See also [[Port Number]] from ECE 4436A.
