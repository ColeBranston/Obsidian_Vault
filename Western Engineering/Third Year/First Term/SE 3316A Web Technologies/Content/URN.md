A **Uniform Resource Name** is a pointer to a resource that does **not** refer to any particular location — it names the thing, not a place to fetch it from.

`urn:isbn:0-471-94128-X` identifies a specific book, wherever any copy of it happens to be.

Not widely adopted when introduced. Its main present-day use is in the semantic web, as identifiers within the **Resource Description Framework (RDF)**.

Contrast [[URL]], which is a location; both are forms of [[URI]].
