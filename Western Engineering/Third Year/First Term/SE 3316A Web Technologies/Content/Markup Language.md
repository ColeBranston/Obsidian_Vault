A **markup language** is a notation for adding formal structure to content — information *about* the content, mixed into the content itself.

Lineage: Charles Goldfarb's **INLINE** system (1970) → **SGML**, Standard Generalized Markup Language (1986) → [[HTML]], which is an SGML language for [[Hypertext]].

[[HTML]] marks up content with **tags**: `<h1>Introduction</h1>` says "this text is a top-level heading" without saying anything about how it should look.
