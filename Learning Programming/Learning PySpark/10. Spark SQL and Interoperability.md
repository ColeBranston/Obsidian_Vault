
- You can register a DataFrame as a temporary **view** and run SQL queries on it:

```Python
df = spark.read.json("people.json")   # columns: name, age, city
df.createOrReplaceTempView("people_table")

result = spark.sql("""
    SELECT city, COUNT(*) AS num_people, AVG(age) AS avg_age
    FROM people_table
    WHERE age >= 18
    GROUP BY city
    ORDER BY num_people DESC
""")
result.show()

```
- Spark SQL queries get converted into DataFrame logical plans, benefit from the same optimizations, and you can join, filter, or union results with other DataFrames.
- You can also persist SQL queries as **global_temp_view** or register with Hive metastore (if enabled), making them accessible across sessions.
