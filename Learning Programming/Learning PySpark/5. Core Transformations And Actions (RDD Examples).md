
Even if you use DataFrames most of the time, it's good to know RDD basics. In PySpark:

```Python
from pyspark.sql import SparkSession

spark = SparkSession.builder.master("local[*]").appName("RDDExample").getOrCreate()
sc = spark.sparkContext   # SparkContext to create RDDs

# Create an RDD from a Python list (parallelize)
nums = sc.parallelize([1, 2, 3, 4, 5, 6])

# transformation: map (returns new RDD, lazy)
squared = nums.map(lambda x: x**2)

# transformation: filter
evens = squared.filter(lambda x: x % 2 == 0)

# action: collect (brings entire result to driver as Python list)
print(evens.collect())   # e.g., [4, 16, 36]

# action: count
print(evens.count())     # e.g., 3

# transformation: flatMap
lines = sc.parallelize(["hello world", "apache spark"])
words = lines.flatMap(lambda line: line.split(" "))
print(words.collect())   # e.g., ["hello","world","apache","spark"]

# transformation: reduceByKey (for key-value pairs)
pairs = sc.parallelize([("a", 1), ("b", 1), ("a", 1)])
counts = pairs.reduceByKey(lambda x, y: x + y)
print(counts.collect())  # [("a", 2), ("b", 1)]

# action: take (get a sample of N elements)
print(nums.take(3))   # e.g., [1, 2, 3]

spark.stop()

```
**Key Points to Mention in an Interview:**

- Transformations (eg. `map`, `filter`, `flatMap`, `reduceByKey`) are lazy - no computation happens until an action triggers them. 
- Actions: (eg. `collect`, `count`, `take`, `saveAsTextFile`)actually execute the DAG
- RDDs are typed as `RDD<T>`. In Python, you don't get compile-time safety, but the concept holds.
- Discuss fault tolerance: RDDs track lineage. If a partition is lost, Spark can recompute it from its parent RDD(s).
