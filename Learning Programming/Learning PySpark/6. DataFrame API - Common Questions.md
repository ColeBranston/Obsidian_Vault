
In PySpark, DataFrames are the go-to interface. Underneath, it's an optimized RDD of `Row` objects plus schema:

```Python
from pyspark.sql import SparkSession
from pyspark.sql.functions import col, avg, count

spark = SparkSession.builder.master("local[*]").appName("DFExample").getOrCreate()

# 1. Read data (CSV, Parquet, JSON, JDBC)
df = spark.read.csv("employees.csv", header=True, inferSchema=True)
# Suppose employees.csv has columns: id, name, department, salary

# 2. Show schema & sample data
df.printSchema()
df.show(5)

# 3. Select specific columns
df.select("name", "salary").show()

# 4. Filter rows
df.filter(col("salary") > 80000).show()

# 5. GroupBy/Aggregations
df.groupBy("department") \
  .agg(
     avg("salary").alias("avg_salary"),
     count("*").alias("num_employees")
   ) \
  .orderBy(col("avg_salary").desc()) \
  .show()

# 6. Add new column (with built‐in functions or expressions)
from pyspark.sql.functions import round
df2 = df.withColumn("salary_in_k", round(col("salary") / 1000, 2))

# 7. Join DataFrames
dept_df = spark.read.parquet("departments.parquet")    # columns: department_id, name
joined = df.join(dept_df, df.department == dept_df.department_id, "inner") \
           .select(df.name, dept_df.name.alias("dept_name"), df.salary)

# 8. Sorting
df.orderBy(col("salary").desc()).show()

# 9. Drop or Rename columns
df3 = df.drop("unused_column")
df4 = df.withColumnRenamed("department", "dept")

# 10. Writing results
df2.write.mode("overwrite").parquet("output/employee_salaries.parquet")

spark.stop()

```
**Interview Tips for DataFrame API:**

- You don't need to use SQL Strings - DataFrame "DSL" (`col("x")`, `df.filter`, `df.select`) is preferred because the Catalyst optimizer can better optimize code than ad-hoc string SQL.
- Mention that functions like `pyspark.sql.functions.*` (`col`, `lit`, `when`, `round`, built-aggregations) are optimized; avoid Python UDFs when possible.
- Emphasize that each DataFrame operation produces a new DataFrame (immutable) and is lazy until an action (eg. `show()`, `collect()`, `count()`, `write()`) is called.
