**Apache Spark** is a distributed data-processing engine designed for large-scale computation. Compared to Hadoop MapReduce, Spark can keep intermediate data in memory (DRAM), making iterative algorithms (eg. machine learning, graph processing) much faster. 

- Spark offers APIs in Scala, Java, Python, and R. **PySpark** is the Python API for Spark, allowing you to write Spark jobs using Python syntax while leveraging the underlying JBVM implementation. 

- Spark's core abstraction is the **Resilient Distributed Dataset (RDD)**, but most prefer the higher-level **DataFrame** and **Dataset** APIs, which provide schema awareness, SQL-like operations, and optimizations via the **Catalyst optimizer**.

- **Why PySpark**? If your team is Python-heavy (data scientists,, ML engineers, or analysts), you can write Spark code in Python and integrate with libraries like Pandas, NumPy, or ML framework. PySpark translates Python calls into optimized JVM code under the hood.
