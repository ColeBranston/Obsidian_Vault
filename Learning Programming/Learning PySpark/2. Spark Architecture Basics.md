
**1. Driver Program**

- Your Python process that defines transformations and actions.
- Maintains the **SparkContext** (for older Spark versions) or SparkSession (Spark 2.x+), which coordinates the cluster

**2. Cluster Manager**

- Allocates resources for the driver and executors. Common options: **Standalone, YARN (Hadoop), Mesos, and Kubernetes**.

**3. Executors**

- Slave JVM process launches on worker nodes.
- Responsible for running tasks (the units of work) and storing data in memory/disk (for caching).
- Each executor runs multiple tasks in parallel (number of cores configurable).

**4. Task**

- A unit of work that applies a transformation (or partial calculation) to a partition of the data. 

**5. DAG (Directed Acyclic Graph)**

- Spark builds a logical plan (DAG) of transformations.
- Only when an **action** is called does Spark optimize (Catalyst) and execute tasks across executors.
