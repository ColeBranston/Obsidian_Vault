
```SQL
-- Retrieve all columns (not recommended in production)
SELECT *
FROM employees;

-- Retrieve only specific columns
SELECT first_name, last_name, salary
FROM employees;

-- Filter rows with WHERE
SELECT first_name, last_name, salary
FROM employees
WHERE salary > 80000
  AND is_active = TRUE;

-- Use LIKE (pattern matching)
SELECT first_name, last_name
FROM employees
WHERE last_name LIKE 'J%';  -- last names starting with J

-- IN, BETWEEN, NULL checks
SELECT *
FROM employees
WHERE department_id IN (1, 3)
  AND hire_date BETWEEN '2023-01-01' AND '2023-12-31'
  AND department_id IS NOT NULL;

```
- `SELECT` chooses columns.
- `FROM` specifies table(s).
- `WHERE` filters rows.
- Boolean operators: `=`, `<>` (or `!=`), `<`, `>`, `<=`, `>=`, `AND`, `OR`, `NOT`.
- `LIKE '%pattern%'` for wildcard matching.
- `IN (val1, val2, ...)` for multiple matches.
- `BETWEEN low AND high` inclusive.
- `IS NULL` / `IS NOT NULL`.
