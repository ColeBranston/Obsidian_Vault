
```SQL
-- Create a simple table for employees
CREATE TABLE employees (
    employee_id    SERIAL PRIMARY KEY,  -- auto-increment integer
    first_name     VARCHAR(50) NOT NULL,
    last_name      VARCHAR(50) NOT NULL,
    department_id  INTEGER,
    salary         NUMERIC(12,2) CHECK (salary >= 0),  -- decimal(12,2)
    hire_date      DATE DEFAULT CURRENT_DATE,
    is_active      BOOLEAN DEFAULT TRUE
);

-- Create departments table
CREATE TABLE departments (
    department_id   SERIAL PRIMARY KEY,
    department_name VARCHAR(100) NOT NULL UNIQUE
);

-- Add a foreign key constraint
ALTER TABLE employees
  ADD CONSTRAINT fk_department
  FOREIGN KEY (department_id)
  REFERENCES departments(department_id);

```
- **Common data types**:
    - `INT`/`SERIAL` (auto-increment), `BIGINT`
    - `VARCHAR(n)`, `TEXT`
    - `NUMERIC(p,s)` or `DECIMAL(p,s)` for precise decimals
    - `DATE`, `TIMESTAMP`
    - `BOOLEAN`
    - `UUID` (if supported)

- **Constraints**:
    
    - `PRIMARY KEY` (uniquely identifies a row)
    - `FOREIGN KEY` (enforces referential integrity)
    - `UNIQUE` (no duplicates)
    - `NOT NULL` (must have a value)
    - `CHECK` (custom condition)
