
- **SQL** (Structured Query Language) is the standard language for interacting with relational database systems (eg. PostgreSQL, MySQL, SQL server, Oracle).
- A **relational database** stores data in **tables** (rows x columns) with explicit relationships between tables via keys.
- Core Tasks:
	- **DDL**: (Data Definition Language): CREATE/DROP/ALTER tables
	- **DML** (Data Manipulation Language): INSERT/UPDATE/DELETE
	- **DQL** (Data Query Language) SELECT queries
	- **DCL** (Data Control) GRANT/REVOKE permissions
