
1. **BEGIN/COMMIT/ROLLBACK**:

```sql
BEGIN;
UPDATE accounts 
SET balance = balance - 100 
WHERE account_id = 1;

UPDATE accounts 
SET balance = balance + 100 
WHERE account_id = 2;

COMMIT;      -- make changes permanent
-- or ROLLBACK; to undo if something goes wrong

```
2. **Isolation Levels** (may vary by engine):
    - **READ UNCOMMITTED**: dirty reads allowed
    - **READ COMMITTED**: no dirty reads (PostgreSQL’s default)
    - **REPEATABLE READ** (prevents non-repeatable reads; PostgreSQL’s default in some versions)
    - **SERIALIZABLE**: full serializability, highest isolation, may cause transactions to abort if they conflict.

3. **Locking behavior**:
    - SELECT … FOR UPDATE (locks rows for update)
    - Beware of deadlocks when two transactions try to lock the same resources in reverse order.
