
```SQL
-- Order by salary descending, then hire_date ascending
SELECT first_name, last_name, salary, hire_date
FROM employees
ORDER BY salary DESC, hire_date ASC;

-- Get top 5 highest paid employees
SELECT first_name, last_name, salary
FROM employees
ORDER BY salary DESC
LIMIT 5;    -- MySQL, PostgreSQL, SQLite

-- In SQL Server:
-- SELECT TOP 5 first_name, last_name, salary FROM employees ORDER BY salary DESC;

-- In Oracle:
-- SELECT first_name, last_name, salary FROM employees ORDER BY salary DESC FETCH FIRST 5 ROWS ONLY;


```

- `ORDER BY` sorts result set; default is ascending (`ASC`); use `DESC` to invert.
- `LIMIT n` (or `TOP n`, or `FETCH FIRST n ROWS ONLY`) restricts rows returned.
- Combine `ORDER BY` + `LIMIT` to get “top N.”
