
```sql
-- Simple CASE
SELECT
  employee_id,
  salary,
  CASE
    WHEN salary >= 100000 THEN 'Executive'
    WHEN salary >= 70000  THEN 'Senior'
    WHEN salary >= 40000  THEN 'Mid'
    ELSE 'Junior'
  END AS level
FROM employees;

-- Searched CASE with ELSE (always include ELSE if possible)
SELECT
  first_name,
  last_name,
  salary,
  CASE 
    WHEN department_id = 1 THEN 'Engineering'
    WHEN department_id = 2 THEN 'HR'
    WHEN department_id = 3 THEN 'Sales'
    ELSE 'Other'
  END AS dept_name
FROM employees;

-- CASE in aggregation (e.g., conditional sum)
SELECT
  department_id,
  SUM(CASE WHEN salary >= 80000 THEN 1 ELSE 0 END) AS count_high_earners,
  SUM(salary) AS total_salary
FROM employees
GROUP BY department_id;

```

- `CASE WHEN … THEN … [WHEN … THEN …] [ELSE …] END`: conditional logic in SELECT, WHERE, ORDER BY, HAVING, etc.
- Useful for pivoting data without an actual PIVOT operator.
