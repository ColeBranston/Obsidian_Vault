

```sql
-- Total salary per department
SELECT
  d.department_name,
  COUNT(*)        AS num_employees,
  SUM(e.salary)   AS total_salary,
  AVG(e.salary)   AS avg_salary,
  MIN(e.salary)   AS min_salary,
  MAX(e.salary)   AS max_salary
FROM employees e
JOIN departments d
  ON e.department_id = d.department_id
GROUP BY d.department_name
ORDER BY total_salary DESC;

-- Filter groups using HAVING (e.g., only departments with > 5 employees)
SELECT
  d.department_name,
  COUNT(*) AS num_employees
FROM employees e
JOIN departments d ON e.department_id = d.department_id
GROUP BY d.department_name
HAVING COUNT(*) > 5;

```

- `GROUP BY` collapses rows into groups; all selected columns must be either in `GROUP BY` or wrapped in an aggregate (`SUM`, `COUNT`, `AVG`, `MIN`, `MAX`, `STRING_AGG`, etc.).
- `HAVING` filters groups (applies after aggregation), whereas `WHERE` filters individual rows before grouping.
- You can group by multiple columns: `GROUP BY col1, col2`.
