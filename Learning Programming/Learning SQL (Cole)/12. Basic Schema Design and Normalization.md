
- **First Normal Form (1NF)**:
    - Eliminate repeating groups; each field contains atomic values.

- **Second Normal Form (2NF)**:
    - In 1NF and every non-key column depends on the entire primary key (no partial dependency).

- **Third Normal Form (3NF)**:
    - In 2NF and no transitive dependency (non-key columns depend only on the primary key).

- **Example**:
    - **Bad**:

```sql
orders(order_id, customer_name, customer_address, product_id, product_name, quantity)

```
Here, `customer_name` and `customer_address` depend on `customer_id`, not on `order_id` directly; also `product_name` depends on `product_id`.

- **Good (normalized)**:

```sql
CREATE TABLE customers (
  customer_id    SERIAL PRIMARY KEY,
  name           VARCHAR(100),
  address        VARCHAR(200)
);

CREATE TABLE products (
  product_id     SERIAL PRIMARY KEY,
  product_name   VARCHAR(100),
  price          NUMERIC(10,2)
);

CREATE TABLE orders (
  order_id       SERIAL PRIMARY KEY,
  customer_id    INT REFERENCES customers(customer_id),
  order_date     DATE DEFAULT CURRENT_DATE
);

CREATE TABLE order_items (
  order_id       INT REFERENCES orders(order_id),
  product_id     INT REFERENCES products(product_id),
  quantity       INT CHECK (quantity > 0),
  PRIMARY KEY(order_id, product_id)
);

```

Now each table has a clear single responsibility.
