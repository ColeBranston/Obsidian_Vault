
Below are common “medium” patterns. Practice writing each from scratch.

```sql
-- Using subquery with LIMIT/OFFSET (MySQL/PostgreSQL):
-- Find the 3rd highest distinct salary
SELECT DISTINCT salary
FROM employees
ORDER BY salary DESC
OFFSET 2 LIMIT 1;

-- Using subquery with NOT IN / >:
SELECT MAX(salary) AS third_highest
FROM employees
WHERE salary < (
  SELECT MAX(salary)  local
  FROM employees
  WHERE salary < (
    SELECT MAX(salary) 
    FROM employees
  )
);

-- Using DENSE_RANK() window:
SELECT salary
FROM (
  SELECT salary,
         DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk
  FROM employees
) t
WHERE rnk = 3;
```
### 15.2. Find Employees Who Have the Same First Letter in First and Last Name

```sql
SELECT first_name, last_name
FROM employees
WHERE LEFT(first_name, 1) = LEFT(last_name, 1);
-- Or in standard SQL (using SUBSTRING):
-- WHERE SUBSTRING(first_name FROM 1 FOR 1) = SUBSTRING(last_name FROM 1 FOR 1);

```
### 15.3. Department with the Highest Average Salary

```sql
-- Using a CTE and ROW_NUMBER (PostgreSQL, SQL Server, etc.)
WITH ranked AS (
  SELECT
    employee_id,
    first_name,
    last_name,
    hire_date,
    ROW_NUMBER() OVER (
      PARTITION BY first_name, last_name, hire_date
      ORDER BY employee_id ASC
    ) AS rn
  FROM employees
)
DELETE FROM employees
WHERE employee_id IN (
  SELECT employee_id 
  FROM ranked
  WHERE rn > 1
);

```
### 15.5. Find Gaps in a Sequence (e.g., missing order IDs)

Assume `orders(order_id)` has integer IDs that should be consecutive:

```sql
-- Using a LEFT JOIN on a generated series (PostgreSQL):
WITH all_ids AS (
  SELECT generate_series(
    (SELECT MIN(order_id) FROM orders),
    (SELECT MAX(order_id) FROM orders)
  ) AS id
)
SELECT id AS missing_order_id
FROM all_ids
LEFT JOIN orders o ON o.order_id = all_ids.id
WHERE o.order_id IS NULL;

-- In MySQL without generate_series, you can join the table to itself:
SELECT t1.order_id + 1 AS missing_id
FROM orders t1
LEFT JOIN orders t2 ON t2.order_id = t1.order_id + 1
WHERE t2.order_id IS NULL
  AND t1.order_id < (SELECT MAX(order_id) FROM orders);

```
### 15.6. Pivot/Unpivot Data

#### Pivot Example (e.g., count of employees by department and gender)
Assume `employees(employee_id, department_id, gender)`, where `gender` ∈ ('M','F'):

```sql
-- In PostgreSQL, using FILTER (preferred):
SELECT
  department_id,
  COUNT(*) FILTER (WHERE gender = 'M') AS male_count,
  COUNT(*) FILTER (WHERE gender = 'F') AS female_count
FROM employees
GROUP BY department_id;

-- Or using CASE:
SELECT
  department_id,
  SUM(CASE WHEN gender = 'M' THEN 1 ELSE 0 END) AS male_count,
  SUM(CASE WHEN gender = 'F' THEN 1 ELSE 0 END) AS female_count
FROM employees
GROUP BY department_id;
```
#### Unpivot Example (convert columns into rows)
Assume a table `monthly_sales(region, sales_jan, sales_feb, sales_mar)`:

```sql
-- PostgreSQL unpivot via UNION ALL
SELECT region, 'Jan' AS month, sales_jan AS sales FROM monthly_sales
UNION ALL
SELECT region, 'Feb' AS month, sales_feb AS sales FROM monthly_sales
UNION ALL
SELECT region, 'Mar' AS month, sales_mar AS sales FROM monthly_sales;

```
### 15.7. Top N per Category (e.g., Top 3 Salaries per Department)

```sql
SELECT employee_id, department_id, salary
FROM (
  SELECT
    employee_id,
    department_id,
    salary,
    ROW_NUMBER() OVER (
      PARTITION BY department_id
      ORDER BY salary DESC
    ) AS rnk
  FROM employees
) t
WHERE rnk <= 3;

```
### 15.8. Find Consecutive Dates / Sessions
Assume `user_sessions(user_id, session_date)`, want to find streaks of consecutive dates:

```sql
-- Use window to compare each row’s date to previous date + 1
WITH seq AS (
  SELECT
    user_id,
    session_date,
    ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY session_date) AS rn
  FROM user_sessions
),
grp AS (
  SELECT
    user_id,
    session_date,
    session_date - INTERVAL '1 day' * (rn - 1) AS grp_id
  FROM seq
)
SELECT
  user_id,
  MIN(session_date) AS start_date,
  MAX(session_date) AS end_date,
  COUNT(*)         AS streak_length
FROM grp
GROUP BY user_id, grp_id
ORDER BY user_id, start_date;

```
