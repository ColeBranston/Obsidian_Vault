  
Assume:

- `employees(employee_id, first_name, last_name, department_id, salary, ...)`
- `departments(department_id, department_name)`

### 6.1. INNER JOIN

Keeps rows where keys match in both tables.

```sql
SELECT
  e.employee_id,
  e.first_name,
  e.last_name,
  d.department_name,
  e.salary
FROM employees e
JOIN departments d
  ON e.department_id = d.department_id
WHERE e.salary > 70000;

```
### 6.2. LEFT (OUTER) JOIN

Keeps all rows from the left table; unmatched right rows become NULL.

```sql
SELECT
  e.employee_id,
  e.first_name,
  e.last_name,
  d.department_name
FROM employees e
LEFT JOIN departments d
  ON e.department_id = d.department_id;
-- Departments will be NULL if an employee has no dept assignment.

```
### 6.3. RIGHT (OUTER) JOIN

Keeps all rows from the right table; unmatched left rows become NULL (less common).

```sql
SELECT
  e.first_name,
  e.last_name,
  d.department_name
FROM employees e
RIGHT JOIN departments d
  ON e.department_id = d.department_id;
-- All departments appear, even if no employee in them.

```
```sql
SELECT
  e.first_name,
  e.last_name,
  d.department_name
FROM employees e
FULL OUTER JOIN departments d
  ON e.department_id = d.department_id;

```

### 6.5. CROSS JOIN

Cartesian product: every row of A × every row of B.

```sql
SELECT e.first_name, d.department_name
FROM employees e
CROSS JOIN departments d;
-- Only use when you really need every combination.

```
