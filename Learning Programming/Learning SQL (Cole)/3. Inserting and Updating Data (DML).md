
```SQL
-- Insert single rows
INSERT INTO departments (department_name)
VALUES ('Engineering'), ('HR'), ('Sales');

-- Insert into employees (specify columns)
INSERT INTO employees (first_name, last_name, department_id, salary)
VALUES
  ('Alice', 'Wong', 1, 85000.00),
  ('Bob',   'Smith', 2, 60000.00),
  ('Carol', 'Jones', 1, 95000.00);

-- Update rows
UPDATE employees
SET salary = salary * 1.05     -- give everyone a 5% raise
WHERE department_id = 1;       -- only Engineering

-- Delete rows
DELETE FROM employees
WHERE is_active = FALSE;       -- remove inactive employees

-- Upsert (PostgreSQL syntax example)
INSERT INTO employees (first_name, last_name, department_id, salary)
VALUES ('Dave','Lee',3,70000.00)
ON CONFLICT (employee_id)
DO UPDATE SET salary = EXCLUDED.salary;

```
- **INSERT**: add rows
- **UPDATE**: modify existing rows (always include a WHERE clause unless you want to update everything)
- **DELETE**: remove rows
- **UPSERT** (INSERT … ON CONFLICT or MERGE in SQL Server) merges insert vs. update logic
