
- "dir" -> displays everything in the current directory (ie. files and folders)
- "ver" -> displays the current version
- "cls" -> clears the command line terminal (may stands for Clear Shell)
- "pause" -> waits for any user input to resume the terminal (ie. go back to the original line)
- "set" -> sets variables (further discussed in [[4. Variables]])
- "echo" -> "echos" back whatever is following (kinda like print functions) ie. `echo %varname%` (see more on [[4. Variables]])
