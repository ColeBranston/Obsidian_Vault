
Every time the `set` command is used it calls on the list of variables existing in the computer or terminal. Every new terminal starts with the original environmental variables found within the `system32` folder path. 

If the `set` command is used without setting a variable the entire called listing will be outputted.

For example: 

![[Pasted image 20250104204216.png]]

If `set` is used but has some characters following without any assignment operator, the set command will print the listing of all variables that start with the characters.

Example:

```bat
C:\Users\Administrator>set user
USERDOMAIN=DESKTOP-KK86GNI
USERDOMAIN_ROAMINGPROFILE=DESKTOP-KK86GNI
USERNAME=Administrator
USERPROFILE=C:\Users\Administrator
```
