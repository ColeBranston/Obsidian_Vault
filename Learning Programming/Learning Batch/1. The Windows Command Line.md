**Can also be called, 'Console'**

**Batch uses an interpreter that interprets the natural text language and executes each command line by  line.**

-> Combination of lines or commands is considered a **Script** which is executed using another program.

Differs from Java and C++ because they are compiled programs themselves, which differs from scripting languages because scripting languages rely on a compiled language to execute the script.

**CMD** has an existing file of batch commands so that it can properly interpret the scripts properly.
