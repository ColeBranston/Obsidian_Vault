1. Docker images are made using the docker language and desktop application to generate a docker image.
2. The images can be run in containers hosted by docker however they are also vital to other services such as cloud services like AWS and Microsoft Azure. 
3. Docker images are the blueprint to making working containers.

- I like to describe containers as a dev environment with all related dependencies in a program including a copy of the program itself. You may run the program in this environment. Containers are almost like a virtual environment that ensures programs run smoothly on any machine
4. Many containers can be run at one time using platforms such as Kubernetes which manage these containers.
