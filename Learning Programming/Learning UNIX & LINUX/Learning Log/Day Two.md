Learning VI
1. Visual editor or VI is a command line text editor used in [[Linux]] to make changes to all forms of files.
- Check out [[Linux Commands]] if you want to know how to open VI
<h1>Instructions</h1>
- There are 2 types of modes that you can use when you enter visual editor:
	1. Command Mode: Active once first entering VI, hit "esc" to enter it from insert mode. Used to run commands relevant to the text editor
	2. Insert Mode: Enter by hitting the "i" key. Insert mode is a normal text edit.
Note: Copy and paste can only be done without shortcuts, and you can only use the arrow keys to navigate from line to line
