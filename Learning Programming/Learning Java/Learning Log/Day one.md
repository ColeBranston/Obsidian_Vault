1. Java is an [[object oriented programming language]] 
2. Programs are established as follows:

```Java
public class nameOfFile{
	public static void main(String[] args){
		//Code goes here
	}
}
```

3. As shown, classes: "nameOfFile" and methods: "main" have a ton of keywords before them that has to do with defining methods and classes in Java. 
4. **public** - enables the method, class, or variable to accessed anywhere in the program or in another program (Expands it's scope)
5. **private** - does the opposite, makes stuff only available to the specific class
6. **static** - static variables are constant among every object, a static method  is the only way to access static variables and other static methods
7. Void - Indicates that nothing from the method is being returned
- Alternatively you could use char, String, Float, int, double
8. A float contains 7 bytes, a double contains 14
