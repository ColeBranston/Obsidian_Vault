NPM allows us to:
1. Reuse our own code in other projects
2. Use code written by other devs
3. Share our own solutions with other developers

Reusable code is called a package. 

Modules, packages, and dependencies are words all used interchangeably. 

We can install a package as a local dependency, using 
`npm i <packageName>`

To install it globally to allow you to use it in any project you would use the following command
`npm install -g <packageName>`

To uninstall a package, run the following command:
`npm uninstall <packageName>`
