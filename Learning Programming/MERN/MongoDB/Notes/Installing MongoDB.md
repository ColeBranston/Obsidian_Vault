1. Download the installer
	https://mongodb.com/try/download/community?tck=docs_server
	Go to this link and download the MongoDB Community installer
2. Download the MongoDB Shell at the following site
	https://www.mongodb.com/docs/mongodb-shell/
3. Unzip the mongo.1 file
4. Go to bin and copy the path for the mongosh.exe file
5. Go to environment variables in your pc and under system variables create a new one
6. Install the VS code extension called "MongoDB for VS Code"
7. Go to the MongoDB icon on the left of VS code and connect via connection string (the default is: mongodb://127.0.0.1:27017)
8. Right click on the IP and select launch MongoDB shell
