- println()method (defined in the PrintStream class) displays a message and/or data to the output (either standard output: console or monitor or file output), and then moves the cursor on the next line (ln)
- println()method has the general form as:
	- System.out.println(expression+expression+…);
<br>
- **Note**: An expression can be any Java expression such as, string constant (one or more characters enclosed by double-quotation marks), character constant (single character enclosed by single- quotation marks), identifier (e.g., variable name, method name), formula (arithmetic and/or logical expressions) or method call (via method name).
<br>
- Example: System.out.println(“Hello world!”);
		This statement outputs the string, Hello world!, to the console and then sends the cursor to the next line (println→ print something and then move to the next line)
- In println() and print() methods, two or more different types of expressions are concatenated by the ‘+’ sign (see the example on the next slide). 
<br>
**Note**: A string-constant is enclosed in double quotation while a character-constant is enclosed in single quotation.

**Print() method: A Variation of println() method**

- print()method has the general form as:
	- System.out.print(expression+expression+…);
- It has the same functionality as println() method, but it does not move the cursor to the next line after printing the required information.

**Note:** We will discuss prinf()method further down in this unit, and that will help us print data and messages with formatting.
