Mid-level Language / Assembly Language: 
- This language assigns short names to commands (e.g., ADD, MOV), instead of using raw binary sequence to represent an instruction set for machine language. 
- Assembly language is easier to understand when compared to machine language 
- Must be translated to machine language
- The *assembler*, a computer program, translates the assembly language into machine language. 
- Still machine/processor dependent
- Example: ADD R1, R2, R3
- Assembly language is still in use. Instead of machine language, this language is used for developing operating systems, device drivers, compilers and other programs that requires direct hardware access.
