CPU is composed of two units:
- Control Unit (CU) : Controls the computer resources (input/output devices, internal/external memory, ALU) by using control signals based on the decoded instructions, also called Processor 
- Arithmetic and Logic Unit (ALU): Performs mathematical operations

**CPU Operations**

- The CPU performs the fetch / decode / execute cycle to process program-information. 
	- Fetch/ get - from main memory (RAM) the CPU’s control unit (CU) fetches the next encoded instruction in the sequence of program instructions. (Note: each instruction is encoded in the form of a binary number.) 
	- Decode The CU decodes the instruction and generates an electronic signal. 
	- Execute – this electronic signal is routed to the appropriate component of the computer (such as the ALU, a disk drive, or some other device). The signal causes the component to perform an operation.
