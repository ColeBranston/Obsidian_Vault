- Normally, objects are electrically neutral: they contain an equal number of positive and negative charges. 
- We can create a charged object by adding or removing electrons
- If we add electrons the object has a negative charge 
- If we remove electrons the object has a positive charge
<br>
- We can charge objects by contact: Example: 
- Glass rod rubbed with silk moves electrons from the glass to the silk. The glass becomes positively charged and the silk negatively charged
