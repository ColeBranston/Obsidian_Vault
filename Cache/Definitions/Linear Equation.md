
$a_1x_1 + a_2x_2+...a_nx_n = b$

Unknowns: $x_1, x_2, ..., x_m$
Coefficients: $a_1, a_2, ..., a_n$

**Ex**:

$$5x_1-7x_2+x_3 = 11 →  Linear$$
$$7x_1x_2 -5x_1 =3 →  \text{Not Linear}$$

- More than one equation →  system
- We investigate the solutions of linear system.


**Ex**:

$$
f(x) = 
\begin{cases} 
x_1+x_2 =2 & \text{if } x\epsilon r \\
x_1-x_2 = 0 & \text{if } x\epsilon r
\end{cases}
$$

$$⇔$$
$$
f(x) = 
\begin{cases} 
x +y = 2& \text{if } x\epsilon r \\
2-y = 0 & \text{if } x\epsilon r 
\end{cases}
$$

Each equation here → Line in real plane
