- Now apply electric field. There’s still lots of collisions, so motions are still *almost* random.
- Between collisions: accelerated due to electric field (in same direction). 
- This causes a net average velocity or *drift velocity* $v_d$.
- Value depends on material (collisions) and is *proportional to the electric field strength*

- Expression $v_d$:
	- $F = qE \text{ and } F=m_e \text{ a. so: } a=\frac{qE}{m}$
$$a = \frac{F}{m} = \frac{qE}{m} = -\frac{eE}{m}$$
	    - $v_d = a\tau = \frac{qE}{m}\tau$
